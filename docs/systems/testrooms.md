# 시험방 — 트랩 시험방 · 몬스터 시험방

진행 층이 아닌 특수 층 둘. 일시정지 메뉴(6·7번) 또는 주소 옵션(`?traproom` · `?monsterroom`)으로 들어가고, 나오는 길은 "처음부터 시작"(테스트 옵션을 지운 주소로 새로 고침)이다. 두 방 모두 스킬·탄을 전부 지급한다. 손으로 쓴 층 파일이라 `genlevel` 을 거치지 않는다.

## 트랩 시험방 (`data/levels/test_traps.json`, 층 번호 99)

- 홀에 밟는 함정(다트·가시·기름·가스), 남쐽 복도에 줄·진자·낙석, 자동 순환 가시판·포자 군락, 다트 회랑. 포자 식물 재생성 레버.
- 출구는 영구 봉인(`exitNeedsKey = true`). 미끼 고블린 2가 문 뒤에 있다.

## 몬스터 시험방 (`data/levels/test_monsters.json`, 층 번호 98) — 2026-09-04 사용자 기획

무한 사냥 테스트 방. 벽으로 둘린 큰 홀(21×15칸)에 기둥 넷, 스폰은 가운데. 출구·함정·전리품이 없다.

- **소환 탭**: 메뉴 창(I·Menu)에 시험방에서만 보이는 `소환` 탭이 생긴다(`MenuTabDef.available`). 들어서면 자동으로 열려 있다. 창이 떠 있는 동안 시간은 멈춘다(다른 탭과 같은 `uiOpen`).
  - 왼쪽: 구현된 몬스터(`implementedEnemyTypes()` — health·damage 를 가진 것, 보스는 아래 구분선) 한 줄에 `[1][3][6]` 마리 버튼과 `살아 n / 목표 m`.
  - 오른쪽: `모두 죽이기`(화면의 몬스터 전부 — 자동 소환이 켜져 있으면 3초 뒤 되살아난다) · `초기화`(전부 없애고 목표·대기열·자동 소환을 끈다) · `자동 소환 ON/OFF`.
  - 조작: 마우스 클릭 · Enter(커서) · 패드 D-패드/왼 스틱 + A. `[6]` 에서 오른쪽으로 한 번 더 밀면 오른쪽 패널, 그 밖은 옆 탭(LB/RB 와 같다).
- **소환 위치**: 시선 앞 부채꼴 — `monsterRoom.summon` 의 `minDist~maxDist`(2~10m), `±arcDeg/2`(90°), 벽이 아닌 바닥, 플레이어에서 `minPlayerDist` 이상, 다른 적과 반지름 겹침 없음. `tries` 번 시도하며 각도를 넓히고, 자리가 모자라면 놓인 만큼만 알린다.
- **초기 상태**: 거머리는 바닥(천장 위장 없음), 구울은 배회(죽은 척 없음), 박쥐는 비행(`cruiseHeight`).
- **규칙**: 소환 몬스터는 `noLoot` — 주머니도 경험치도 없다. 보스를 잡아도 출구 봉인 해제 개념이 없다(`Exit.tick` 은 시험방에서 돌지 않는다). 플레이어 HP·MP 는 소모되되 초당 `monsterRoom.regen.healthPerSec/manaPerSec` 만큼 자동으로 찬다. 스킬은 전부 익히되 마나 무한(스킬 테스트)은 끈다.
- **자동 소환(규칙 A)**: 종족별 목표 수(소환한 총합)를 두고, 소환한 종족이 죽으면 `autoRespawnDelayTicks`(180 = 3초) 뒤 그 종족 1마리를 되채운다. 이미 목표만큼 살아 있으면 취소. 자동 소환을 끄면 대기열을 비운다. 층을 옮기면 소환 상태는 전부 비워진다.
- 시스템: `systems/Summon.ts`(배치·목표·대기열, `enemy_died` 구독) · `render/SummonPanel.ts`(탭 패널) · 이벤트 `summon_spawned` `summon_reset`.
